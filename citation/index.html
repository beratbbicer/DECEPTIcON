Citation#

Citation is a condition of access to the data, not a request. Any publication, presentation, or derivative dataset that uses the DECEPTIcON release must cite the work listed under Publication below. Work that derives from the extension release must also cite the extension paper once it is published.

Publication#

DECEPTIcON: Bridging Gaps in In-the-Wild Deception Research (Scholar) (IEEE Xplore)

Berat Biçer, Bahadır Durmaz, Serhat Aras, Hamdi Dibeklioğlu. IEEE Transactions on Affective Computing, vol. 16, no. 4, pp. 3452–3464, 2025. DOI: 10.1109/TAFFC.2025.3591205.

What counts as use#

A publication uses the release if it trains on the artifacts, evaluates on the fixed split, or reports numbers derived from either. Reviews and surveys that discuss the dataset should cite the work listed above. The terms of use restate citation as a condition of access.

Where the citation appears#

Citation is restated in the access terms on the data access page and in a CITATION file inside the released archive. The archive also carries a README that repeats the terms.

Research access

The release is distributed under a research-use agreement. Terms, eligibility, and the request procedure are on the data access page.
